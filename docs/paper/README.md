# Draft paper

**A measurement digital twin for large-volume metrology planning: from station pose to
conformity decision risk** — draft manuscript, kept as an editable document:
https://claude.ai/artifact/MLSdDrFc4VV8bzJLY2RsfU (export to Word, PDF or Markdown from there).

* Every number in it comes from this repository: `docs/cell_experiment.md` gives the runs,
  `results/cell_results_datum.json`, `cell_results_datum_no_network.json` and
  `cell_sensitivity.json` the data, `python -m viz.make_paper_figures` the figures
  (`results/paper_fig1..7`).
* `references.md` is the numbered reference list; `reference_notes.md` records where each
  entry came from. Volume, pages and DOI still need completing from the publisher pages,
  and each source should be read in full before submission: the draft relies on abstracts
  for the related-work statements.
* The cell and all process data are synthetic placeholders; the paper says so.
